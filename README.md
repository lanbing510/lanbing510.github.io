# 冰蓝记录思考的地方


### 说明

博客基于Jekyll，在PainterLin的框架下进行搭建。

博客模板预览：[冰蓝记录思考的地方](http://lanbing510.info)


### 增加功能

1 修改了整体框架的色调风格。

2 增加了MathJax插件，可以随意插入公式（由JavaScript生成，兼容性高于图片公式，且不受限于图片公式的服务器）。

3 增加了不蒜子进行流量统计。

4 修复了网站地图，使Google WebMaster加入索引。

5 修改了面版及页面呈现风格。

6 增加了可折叠代码块的功能。

7 美化了滚动条，并为文章的目录视图加入了滚动条功能，修复了以前的Bug。

8 增加了分享到微博微信等功能[已删]。

9 增加了站内搜索功能。
